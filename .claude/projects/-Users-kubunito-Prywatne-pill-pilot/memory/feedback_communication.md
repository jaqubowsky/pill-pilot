PRD nie powinno zawierać technicznych rzeczy — przenieść do odpowiednich plików.
**Why:** User chce czysty podział: PRD = produkt, tech-stack = stack/konwencje, technical-requirements = schematy/logika.
**How to apply:** Przy edycji dokumentacji pilnować podziału odpowiedzialności między plikami. Każdy plik powinien linkować do pozostałych.
